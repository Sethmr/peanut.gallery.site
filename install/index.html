§ 02 · Setup
1

Add to Chrome

Click Add to Chrome in the Web Store. Chrome will show a permission summary — accept it. The peanut lands in your ⋮ extensions menu.

Click the puzzle-piece icon at the right of the address bar, find Peanut Gallery, and click the pin to keep the peanut visible in your toolbar.

2

Open the side panel

Open any YouTube tab — a podcast, an interview, anything with audio. Click the peanut in your toolbar. Chrome opens the side panel on the right.

First-time only: a four-step guided tour walks through the Critics dial, persona pack switcher, and the Backend & keys drawer.

3

Press Start

Hit the red Start Listening button at the top of the panel. Tab audio is captured silently — no screen-share picker, no playback interference.

The four-persona booth fires within 30 seconds. Pin / upvote / quote-card any reaction you love.

Install FAQ.

§ 04 · Q & A

Will Peanut Gallery slow down my browser?

Not noticeably. The extension is event-driven — it only does work when a session is running. When idle, it's a sleeping service worker that wakes on toolbar click. No background polling, no telemetry, no analytics inside the extension.

Does YouTube detect or block this?

No. The extension uses chrome.tabCapture — the same API Otter and Fireflies use to silently capture meeting audio. There's no screen-share picker, no DOM scraping, no playback interference. YouTube has no way to detect it.

Can I use it on the Brave / Arc / Edge browser?

Edge 116+ runs the same engine and works fine — install from the Chrome Web Store and it'll prompt to add. Brave + Arc are Chromium-based and usually work; the Side Panel API needs to be present, which is true on recent versions of both. Officially we test on Chrome.

What permissions does it ask for?

Three: Side Panel (to live in the side panel), Tab Capture (to listen to the active tab's audio), and Storage (to persist your settings + license key locally in chrome.storage.local). No host permissions until you point at a custom backend.

How do I uninstall?

Right-click the peanut in your toolbar → Remove from Chrome. All local storage is cleared on uninstall. If you had a Plus subscription, cancelling the Chrome extension does NOT cancel the Stripe subscription — open the side panel before uninstalling and use Plus → Manage, or email support@peanutgallery.live.

Why isn't it on the Edge or Firefox add-on store?

Edge mirrors the Chrome Web Store — the same install link works. Firefox port is on the v2.x roadmap once the Side Panel API gap closes (Firefox uses a different sidebar mechanism that needs a separate code path).
