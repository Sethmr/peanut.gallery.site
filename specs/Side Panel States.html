Critic state

Speaking,
idle, muted.

Each mug's five-bar waveform reads the critic's own channel — not the transcript. Animated = composing. Flat grey = listening. Struck-through = muted.

Wire state

Live, standby,
replay, down.

Masthead dot + ticker label tell the operator what the wire is doing. Red = live. Grey = standby. Yellow = replay or cap. Red+still = error.

Source

Any tab
with audio.

Livestreams, podcasts, webinars, Zoom, YouTube. The operator taps Go Live in the active tab — no URL drop, no browser permission modal beyond the first session.
