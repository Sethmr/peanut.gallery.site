Privacy Policy

— The short version below —Last updated · April 21, 2026

Short answer: your keys stay on your machine, your audio is transcribed in real-time and discarded, nothing is logged. No accounts for the free tier. For Peanut Gallery Plus ($8/mo) we store a license key, your signup email, and a weekly hours counter — nothing else. Payment data lives at Stripe, never here.

Peanut Gallery is a Chrome extension that listens to the audio of the tab you’re currently on, transcribes it in real-time, and streams AI persona reactions back to a native Chrome side panel. This policy describes what happens to the data involved on both the free/BYOK path and the paid Plus path.

What the extension collects

The extension only captures audio when you explicitly click Start Listening from the side panel. Specifically:

  • Tab audio, via the standard chrome.tabCapture API — the same API used by Otter.ai, Fireflies, and other transcription tools. Capture stops the moment you click Stop or close the tab. No audio is recorded to disk.
  • API keys you type into the side panel (Deepgram, Anthropic, xAI, optionally Brave Search). These are stored locally via chrome.storage.local so you don’t have to retype them every session. They are sent to the server you configure via request headers so it can call those providers on your behalf. They are never uploaded to anyone else.
  • Your Peanut Gallery Plus license key (if you have one). Stored the same way — chrome.storage.local, one per device, sent to the hosted backend as an X-Subscription-Key header to authorize the session and decrement the weekly-hours counter. Nothing else.
  • The URL and title of the tab you’re capturing from, passed to the server for display purposes only.

What the server does with it

You can point the extension at two kinds of servers: the default hosted backend at peanutgallery.live, or a server you run yourself (the self-host path in the Operator’s Manual). In both cases, the server:

  • Forwards audio to Deepgram for real-time transcription.
  • Sends short transcript windows to Anthropic (Claude) and xAI Grok to generate persona reactions, and to your chosen search engine (Brave Search or xAI Live Search) for live fact-checks.
  • Streams results back to your browser via Server-Sent Events (SSE).
  • Discards the session entirely when you click Stop or the tab closes. Transcripts and responses are held in memory during the session and are not written to disk, not logged, and not persisted.

The hosted backend at peanutgallery.live

When you use the default server, your API keys (BYOK) or license key (Plus) travel to the hosted backend inside the request headers for that single SSE stream, are forwarded to the relevant providers (Deepgram / Anthropic / xAI / Brave) for that session, and are discarded at session end. API keys are never logged, never persisted. You can audit the exact handling in the transcribe route on GitHub: app/api/transcribe/route.ts.

Peanut Gallery Plus — subscription data

If you subscribe to Peanut Gallery Plus, the hosted backend maintains a minimal record of your subscription so the license key can be validated and the weekly usage cap enforced:

  • License key — a randomly-generated pg-xxxx-xxxx-xxxx code that identifies your subscription. Stored server-side alongside the fields below.
  • Your signup email — used to deliver the license key and the Stripe Customer Portal link on cancel/recovery. Not used for marketing and not shared with anyone.
  • Your Stripe subscription ID — an opaque identifier Stripe gives us so we can tie webhook events back to the correct subscription.
  • A weekly usage counter — total minutes of transcription consumed in the current 7-day window. Resets at the window end. This is the only engagement signal we keep; it exists to enforce the 16 h/week cap.

No transcripts, audio, persona responses, or tab URLs are stored against the subscription record. Session activity is forgotten at the end of every session — same as the free/BYOK flow.

Payments — processed by Stripe

Payments for Peanut Gallery Plus are processed by Stripe. Your card details go to Stripe directly and never touch our servers. We receive an opaque subscription ID, the email you used at checkout, and webhook events about subscription lifecycle (created / updated / cancelled / payment failed). The full list of what Stripe stores on your behalf is in their privacy policy.

Emails — delivered by Resend

Transactional emails (the license key on signup, the Stripe Customer Portal link on cancel, key recovery on lost-key requests) are sent through Resend. Resend holds the send logs (recipient address, send timestamp, delivery status) under their terms; we do not cc ourselves, forward, or bulk-export those emails. We never send marketing email.

Third-party services

When Peanut Gallery calls a third-party AI provider on your behalf, data handling is governed by that provider’s terms:

  • Deepgram — speech-to-text.
  • Anthropic (Claude) — persona responses.
  • xAI — Grok persona responses and optional Live Search fact-checks.
  • Brave Search — live fact-checking queries.
  • Stripe — payments for Peanut Gallery Plus (no card data on our servers).
  • Resend — transactional email for subscription lifecycle messages.

Analytics

The landing page at peanutgallery.live uses Google Analytics to measure aggregate page visits. No personally identifying information is collected beyond the standard request metadata (IP, user agent, referrer) that Google Analytics receives. The Chrome extension itself does not include any analytics.

What Peanut Gallery doesn’t do

  • We don’t have user accounts, passwords, or OAuth for daily use. BYOK has nothing to sign up for. Plus uses a license key emailed to you once; there’s no login surface.
  • We don’t log or store your audio, transcripts, or API keys.
  • We don’t sell data. There’s nothing to sell.
  • We don’t run background capture. The extension only listens while you’re actively in a session you started.
  • We don’t track you across sessions for analytics. The only per-subscription counter is the weekly-hours meter, which exists solely to enforce the 16 h/week cap and is not used for anything else.
  • We don’t send marketing email. Transactional only — license key delivery, cancel/portal link, lost-key recovery.
